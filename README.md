# Vityarthi-Project
>> PYTHON GAME HUB

>About the Project

Python Game Hub is a simple console based application developed using Python.
The project brings multiple games and activities together in one program. The user can select an option from the main menu and play the selected game.
The project was created to practice basic Python programming concepts such as functions, modules, loops, conditional statements, lists, random number generation, exception handling and file handling.

>Games and Activities

The project contains the following:

1. Tic Tac Toe
2. Rock Paper Scissors
3. Coin Toss
4. Number Guessing
5. Python Quiz
6. Dice Roll
7. Score History

>Project Structure


Python Game Hub

>Description of Files

>main.py

This is the main program of the project.
It displays the main menu and calls the required functions from the other Python files.

>games.py

This file contains the following games:
Tic Tac Toe
Rock Paper Scissors
Coin Toss
Number Guessing
Dice Roll

>quiz.py

This file contains the Python programming quiz.
It asks questions, checks the answers and calculates the final score.

>scores.py

This file contains the functions used to save and display game results.

>scores.txt

This text file stores the results of completed games and quizzes.

The main menu will appear.

> Score Storage

The project uses `scores.txt` to store game results.
When a game is completed, the result is saved in the file.
The View Scores option reads the file and displays the stored results.

> Input Validation

The project includes basic input validation.
For example, Number Guessing checks whether the entered value is a valid number between 1 and 20.
Tic Tac Toe checks whether the selected position is between 1 and 9 and whether the position is already occupied.
The other games also check for valid choices.
