>Project Statement

> Project

Python Game Hub

> Problem Statement

Small Python games are often made as programs. This means users have to open and run each game individually. That can be inconvenient. The Python Game Hub solves this problem by bringing simple games together into one console-based Python application.
The app shows a menu where the user can choose a game. The games available include Tic Tac Toe, Rock Paper Scissors, Coin Toss Number Guessing, Python Quiz and Dice Roll.
The project also includes a score system. It saves results from completed games in a text file. Users can view their results later through the application.

> Objectives

The main objectives of the project are:
1. To create a Python-based game application.
2. To combine games into one single program.
3. To build a menu-based interface.
4. To practice using Python functions and modules.
5. To work with loops and conditional statements.
6. To use number generation.
7. To handle incorrect user input properly.
8. To demonstrate file handling in Python.
9. To. Show game results.
10. To improve programming skills and problem-solving abilities.

> Proposed Solution

The solution is a Python application. It uses files for different parts of the program.
The main program controls the menu. Calls the right functions. Games are stored in `games.py`. The Python quiz is in `quiz.py`. Score management is handled by `scores.py`.
All results are saved in a file called `scores.txt`.

> Expected Outcome

When finished the application should let a user:
1. Choose a game from the menu.
2. Play the selected game.
3. See the result of the game.
4. Take the Python Quiz.
5. Save game results when needed.
6. View past results that were saved.
7. Go back, to the menu after playing.
8. Exit the program safely.

> Technologies Used

Python 3 is the programming language used.

The project uses Python’s built-in `module to generate random outcomes. It also uses file handling to save scores.

> Scope of the Project

This is a beginner-level console application. It focuses on helping understand core Python concepts through hands-on practice.
Later the project could grow by adding games, a graphical user interface, player accounts, difficulty options, detailed stats and database support.
